Privacy Policy

Last updated: 15 October 2026

This policy covers Kabir Raahi Uploader, a private application used only by the owner of the YouTube channel Kabir Raahi (@KabirRaahi).

What the app accesses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload the channel's own videos, set titles, descriptions, tags, thumbnails, playlists and publish times, and the YouTube Analytics API to read the channel's own statistics.

What data is stored

The app stores only an OAuth access token on the owner's own computer so that uploads can continue. It does not collect, sell or share any personal data, and it does not access other users' accounts or data.

Third parties

Data is sent only to Google (YouTube) through Google's official APIs. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
